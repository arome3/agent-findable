How Payment Works

AgentFindable uses MPP (Micropayment Protocol) for seamless pay-per-request billing.

1
Request Hit any paid endpoint
2
402 Challenge Server returns payment terms
3
Auto-pay Wallet pays USDC on Tempo
4
Result Response with payment proof

When you hit any paid endpoint, the server returns 402 Payment Required with an MPP challenge. Your Tempo wallet automatically pays in USDC on the Tempo blockchain (~500ms finality), then retries with payment proof. You only pay for what you use. No subscriptions, no API keys, no accounts.
